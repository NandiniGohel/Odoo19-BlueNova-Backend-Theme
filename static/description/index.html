BlueNova Backend Theme

A responsive visual reskin of the Odoo backend, tuned for CRM.

Activate the app and the theme applies to the whole web client. Uninstall it and Odoo goes back to its stock look — no data is touched.

What it changes

  • Design tokens — Deep Indigo primary, tiered white surfaces, 8/12/16px radii
  • Typography — Inter and Poppins, bundled in-module (no CDN request)
  • Top navbar — restyled colors and typography
  • Left app sidebar replacing Odoo's apps dropdown, with bundled app icons painted through a CSS mask: grey at rest, blue on hover, a stronger blue for the app you are in
  • Light / dark mode, switched from the sidebar footer and remembered per browser
  • Control panel styled as a page header
  • Kanban board — 320px stage columns, glassmorphic cards with an accent spine
  • CRM pipeline stat banner above the pipeline (no extra RPC)
  • Buttons, badges, spacing, shadows and responsive tablet/mobile breakpoints

Settings → Theme Settings

  • Live colour pickers for the core palette, top bar, search box, sidebar, active-app highlight and semantic colours — no SCSS edits or asset rebuild, changes apply on save
  • Uploadable brand image for the sidebar and a login background image (light and dark)
  • Export / Import / Reset — download the current palette as a JSON preset, re-import it later, or reset to the compiled defaults
  • Every colour is validated before it is saved and again before it is rendered

Themed dashboard, login, signup and public page

  • KPI dashboard — tiles for open opportunities, quotations, RFQs, posted invoices, open tasks, transfers and active employees, shown only for apps the current user can read; can optionally open right after login
  • Login, signup and reset-password pages pick up the same palette, plus an optional logo and tagline
  • Optional public page at "/" for anonymous visitors — off by default, and it stands down automatically once the Website app is installed

Safe by design

The module adds a small settings model, a transient import wizard, and two opt-in controller hooks (login redirect, public home page) — no new stored business data. It can be activated and removed at any time without migrating or losing data.

Known limits

  • Odoo's slide-in app menu on small screens (below md) is left as-is.
  • Dark mode covers the surfaces this theme styles plus the main list / form / kanban / dialog chrome. Odoo compiles most other colours into SCSS, so deeper corners — some reports, iframes and third-party widgets — can still show light patches.
  • No fixed bottom footer bar and no floating action button.
