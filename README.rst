======================
BlueNova Backend Theme
======================

BlueNova Backend Theme module for Odoo 19 Community and Enterprise editions.
This is a minimalist, glassmorphic backend theme for Odoo 19 — a persistent
app sidebar, light/dark mode, a themed login/signup/reset-password flow, an
optional public home page, a KPI landing dashboard, and an in-app Settings
screen for recolouring the whole theme without touching SCSS.

Configuration
=============

* https://www.odoo.com/documentation/19.0/administration/install.html
* Install this module like any other custom addon, then go to
  **Settings → Theme Settings** to recolour the palette, upload a brand
  image, and set an optional login/dashboard preference.
